# nurmohammad126641.github.io

Portfolio website of **Nur Mohammad Siddiq**, Data, BI & Automation Engineer in Dhaka.

**Live site:** https://nurmohammad126641.github.io

- Plain HTML, CSS and JavaScript. No framework and no build step.
- Built for phones first: a bottom navigation bar, swipeable cards and diagrams that fit the screen.
- Includes an "Ask my AI agent" demo. It picks a tool, the tool returns real data from my profile, and the answer uses only that data.

To run it locally, open `index.html` in a browser or serve the folder with any static file server.
