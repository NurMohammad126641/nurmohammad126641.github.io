Backend Padakhep · 2026

Overdue Tracking Platform

Replaced manual Excel overdue tracking across 406 branches with one platform, now used by 4,000+ staff.

Read the full story
What I built
A production Django REST Framework platform on PostgreSQL, with Celery and Redis for background jobs, secure authentication and REST API integration. It covers overdue member entries and actions, field visits, legal actions and reports.
How it rolled out
I first presented it to the head office executive team, then piloted it in the Karwan Bazar branch only. I trained every staff member there, including using it on their phones, and collected their feedback before the wider rollout.
Result
One source of truth for overdue loans, used daily across all 406 branches.
  • Django REST Framework
  • PostgreSQL
  • Celery
  • Redis
  • Auth & permissions

Data Padakhep · 2025

Branch Report Automation Engine

A report that took 2–3 days of manual work now runs in under 2 hours, with 100% accuracy.

Read the full story
What I built
Python REST API automation that pulls all 406 branches in parallel, recovers failed pulls on its own, validates every result and merges them into a ~730K-row master report.
The hard part
At this scale, some branch calls always fail. Self-healing retries and validation are what make the output trustworthy, not just fast.
  • Python
  • Multithreading
  • REST APIs
  • Pandas
  • Data validation
